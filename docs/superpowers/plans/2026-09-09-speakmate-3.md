# SpeakMate 3.0 Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: use superpowers:subagent-driven-development or superpowers:executing-plans. Execute and review each task before the next. Use TDD; do not claim unperformed verification.

Goal: implement the approved local-only mobile learning loop without losing 2.3 data.
Architecture: Next.js App Router + pure domain rules + IndexedDB repositories. Static curated content; no learning-data network calls. Preserve cloud ports only.
Tech Stack: existing React/TypeScript/Zustand/idb/Zod/Vitest/Playwright; no new dependencies required.
Spec: `APP_SPEC.md` (binding). Base commit: `aacbffd`.

## Global Constraints

- 严格零费用；不启用订阅、云数据库、云模型或 MySQL。
- 练习正文、录音、笔记、任务和积分只在设备本地处理。
- 五项导航固定：目标、练习、场景、记录簿、我的；最大 480px、44px 触摸区域、安全区。
- 标题“随时开口”不拆行；按钮“开始练习”；增加“随时随地自在说英语！”。
- 本地学习助手不冒充通用 AI；未收录内容明确标注，禁止伪造语义/音素评分。
- 示例榜标注“示例数据，非真实好友排名”，不进入真实统计、账本或备份。
- 保留旧数据和 2.3 生产回退点；未经完整验证不发布。
- Only edit the authorized isolated worktree. Read AGENTS.md and relevant bundled Next docs before code. Apply patches, no shell file-writing tricks. No subagents from worker/reviewer; controller coordinates. Full suite once before task commit; focused tests during iterations.
