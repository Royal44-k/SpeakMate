## 2. 在新环境重现

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

浏览器测试需可用的 Playwright 浏览器。现有 Windows 配置使用 Edge 通道和 WebKit；按实际配置准备浏览器，勿用日常登录 profile。若没有 WebKit，可由操作者执行 `pnpm exec playwright install webkit` 下载免费测试运行时；它不是 iOS 模拟器。

终端 A：

```bash
pnpm exec next start -p 3100
```

终端 B（PowerShell）：

```powershell
$env:PLAYWRIGHT_BASE_URL = 'http://127.0.0.1:3100'
pnpm test:e2e
```

`PLAYWRIGHT_BASE_URL` 防止测试工具再启动第二个 Next 服务器。专项应使用其 README 所记端口、构建和前提；应急测试可能需要另起只读构建，不能盲目把全部历史专项当作同一环境命令。结束只关闭自己启动的测试进程，不清理真实浏览器数据。

## 4. 如何保存新证据

记录源码 SHA、Node/浏览器版本、构建 ID、命令、退出码、开始时间、通过/失败/跳过数量、测试数据是否合成和具体限制。截图标注尺寸及页面，不把参考图当实现图；网络审计记录方法和目的地，公开前检查凭据及私人内容。

归档内保留历史失败及修复链路。trace ZIP、大型合成备份、`.last-run.json` 等未公开文件列在[排除清单](../archive/excluded-test-output.json)，原件留在原电脑。缺少公开附件不等于该检查自动通过；已发布汇总记录应按其原始范围解读。
