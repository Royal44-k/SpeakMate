# 本地口语练习助手说明

状态：3.0 使用说明草稿。语料试点和本地引擎已经实现，完整语料与页面接入仍在开发；下文不是已上线功能的声明。正式发布前按最终界面复核入口名称。

## 它能做什么

SpeakMate 本版不连接云端模型。练习依据已经编写、检查的场景、问题、参考表达和规则在设备内运行。目标是帮助你反复开口、比较表达、记录词句，再有针对性地练习。

同一个场景有分级内容及不同长度。开始前先阅读背景与角色；其中可能约定饮品、地点或服务条件等默认事实，后续问题会沿用这些条件。所有场景都是模拟，不会替你下单、付款、预约或联系他人。

## 三种反馈分别是什么意思

|反馈范围|可以据此了解什么|不能据此下什么结论|
|---|---|---|
|已匹配表达|在当前问题和语境中匹配到了已收录表达，可推进其明确支持的场景任务|不能证明整段自由表达、发音或整体英语水平都准确|
|部分覆盖|找到其中某个词或短语的已收录资料，可查看该部分的用法|不等于完整句子的结构和语义已经被解析|
|尚未覆盖|保留你输入的原文；仍可记录、添加备注和自行回忆练习|不代表这句话有语法错误，也不表示它一定不合适|

本地助手不会根据“没有发现错误”就判定表达完全正确，也不生成音素分数或发音准确率。句中代词所指不明时，不把猜测当成确定解释。

## 怎么让练习更顺畅

先尝试独立回答，需要帮助时再查看当前问题的参考表达。参考答案与当前问题对应；改写后是否被识别，取决于改写内容是否在已收录范围内，不能仅凭点击过某个参考答案就算确认。

页面将提供请求澄清、表达困难、调整已确认选择和结束对话等操作。请通过可见入口使用这些操作，不需要背诵特殊口令。已确认的信息不会为了凑轮数再次询问；主动修改选择时，与它相关的后续信息可能需要重新确认。

短练、标准和拓展分别以约 3、6、10 个用户轮次组织。澄清或暂未覆盖的回答也占用本轮练习机会，因此可能出现“练习已结束，但部分场景目标尚未确认”。这不是能力不合格，也不应受到积分惩罚。可记录本次表达，或重新开始一个完整情境。

## 暂停、结束与任务奖励

正常走完本轮后，还需要明确确认完成；停留在确认页或刷新页面不会重新提问，也不会重复结算。普通返回或暂时离开会保留当前进度，不等于主动放弃。主动选择停止或拒绝结束，则不是完成今日任务。

任务奖励依据实际完成的练习流程，而不是英语零错误。正常轮次中至少有一次非空表达，并在最后确认完成，才可能满足对应场景任务；全程只点帮助或提前停止不满足这一条件。是否已匹配参考表达与是否付出了练习努力是不同的提示，不能把任务积分当作英语能力分数。

从今日任务进入的练习沿用该任务的等级与长度；自由练习可以按当前选择另开一轮。修改个人等级后，今天已经开始的任务仍保留原目标，因此页面会区分“个人等级”和“今日任务等级”。跨午夜可以继续原任务，完成后只结算一次，打卡记在实际完成的北京时间日期。

旧版对话会保留可阅读的文字，但不会自动变成新版场景状态或追溯发放任务积分。需要使用新版语料时，请明确开启新一轮，不必删除旧记录。

## 首次加载与离线使用

公开场景资料仍需要首次下载；“学习内容在本机处理”不等于从未访问过网站也能断网启动。页面外壳就绪与所选语料就绪是两项不同状态，只有相应资源已准备好时才能据此尝试离线练习。未准备好的内容应给出重试说明，不会悄悄替换为其他等级或场景。

正式发布前会验证下载后断网的新建、继续、记录和复习流程。此说明目前不代表这些离线测试已经通过；若手机无法加载网址，也不能靠本地 MySQL 解决网络访问问题。

## 录音、文字与朗读

能够确认设备支持本地转写时，才会启用该能力；否则使用录音回听加文字确认。文字确认是你输入或核对的内容，不冒充系统成功识别的结果。

录音只用于当前练习，不上传，也不进入长期备份。朗读只使用能够确认的本地英语音色；没有可用音色时，页面应说明原因，不悄悄改用远程语音。设备是否支持本地音色与转写，需要在实际使用的手机上确认。

## 记录和复习

已覆盖的词句可以查看中文释义、搭配、语体、易错点和分级例句。未覆盖词句也能保存和添加个人备注，但不会展示拼凑出的确定语法结论。

同一个词句可以合并多次记录来源，但不同场景下不一定是同一种意思。解析会指明当前选择的来源；切换来源时应重新查看覆盖范围，不把某个场景的已收录释义套用到所有记录。

“记得／模糊／忘记”是自己的回忆评价，与规则识别结果分开。默认复习间隔只是安排练习的产品策略，不宣称是对每个人最有效的记忆周期。具体数据导出与保存限制见[本地数据与备份说明](./3.0-local-data-and-backup.md)。
