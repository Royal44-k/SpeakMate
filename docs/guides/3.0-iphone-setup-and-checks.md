# SpeakMate 3.0：iPhone 安装与自查指南

状态：3.0 安装与自查说明，2026-09-13 独立网址发布更新。新版匿名访问和线上资源完整性检查已通过，详见[发布记录](../releases/3.0.0-independent-url-2026-09-13.md)。系统菜单来源见下文 Apple 官方文档；下列真机检查仍待执行，不能用桌面 HTTP 或候选 READY 替代。

## 开始前

SpeakMate 采用 PWA 网页 App 路线，不需要安装开发者证书、描述文件或原生安装包，也不依赖本地电脑和 MySQL 开机。**新版地址为 [speakmate-v3.vercel.app](https://speakmate-v3.vercel.app/)**；[旧地址](https://speakmate-pwa.vercel.app/)继续提供 2.3，不会自动变为新版。

请使用自己熟悉的安全网络打开 Safari。若此前已有练习数据，先确认并保留现有入口及备份，不通过清理站点数据、删除主屏幕入口或更改身份来排查问题。

## 添加到主屏幕

以下依据 Apple 的 iOS 26 手册；更早系统的入口位置和文字可能不同，不能据此推断最低兼容版本。

1. 在 Safari 中打开并核对 `https://speakmate-v3.vercel.app/`，不要从旧主屏幕图标进入后误认为已升级。
2. 进入共享菜单：紧凑布局通常先点“更多”再点“共享”；顶部或底部布局可直接点共享按钮。
3. 在操作列表选择“添加到主屏幕”。缺少该项时，到列表底部的“编辑操作”中添加它。
4. 开启“作为网页 App 打开”，名称可改为“SpeakMate 3.0”，然后点“添加”。
5. 回到主屏幕，亲自点击新图标，确认打开预期的 SpeakMate 页面。

系统路径来源：[Apple：在 Safari 中将网站变为 App](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/ios)。图标出现只证明入口已添加，不证明离线资源已下载、记录已迁移或备份已成功。

旧图标和旧数据可以保留。需要迁移时，先从原来确实能看到记录的旧入口导出，在准备长期使用的新版入口预览并确认恢复；若该入口已有另一份学习身份，先分别备份，不强行合并。新旧网址及 Safari/主屏幕入口不能假定自动共享数据。旧版任务不会因迁移补发 3.0 积分，部分旧对话只能作为历史查看；详见[备份迁移说明](3.0-local-data-and-backup.md)。

若你使用的是较早 iOS，找不到某个开关时不要反复删除重装；记录系统版本与现有菜单，按该版本的官方手册确认。不要求为了本指南立即升级系统。

## 先走一遍完整学习流程

以下是 3.0 发布后的预期检查，请先使用不含隐私的测试表达；不要修改真实历史来凑测试条件。

1. 在“目标”完成或查看引导，选择英语等级与每日时长；已经完成引导时，应直接看到今日计划。
2. 从任务卡进入练习，检查场景、任务等级和预计轮数；自由新练习则应使用当前个人选择。
3. 阅读背景和角色，尝试文字回答；再短暂录音、停止并回听。不支持本地自动转写时，应使用录音回听加文字确认，而不是假显示转写成功。
4. 从参考表达或对话历史保存一句话。分别尝试可见记录按钮与原生长按选词；保存后不应被迫退出对话。
5. 完成所选场景要求的练习轮次，再明确确认结束，查看报告并返回来源。一条回答不等于整个任务完成；重新查看报告不应再次发奖。
6. 在“记录簿”找到词句，检查来源、解析覆盖提示和备注；完成一次自评复习或对应模拟练习，再回到原笔记。

若任何一步失败，记录当时的提示与页面，不以清空数据作为通用修复。解析“尚未覆盖”不代表你说错了；没有本地英语音色也不代表整个应用不可用。详见[本地练习助手说明](./3.0-local-practice-assistant.md)。

## 确认导出文件确实保存

为了保持本地方案，请将导出文件存于“我的 iPhone”，不要主动选择 iCloud 云盘或第三方网盘。本应用不会代你改变系统下载位置；如果系统本来使用云盘，导出前先由你确认保存位置。

1. 在 SpeakMate 数据管理中发起导出后，保留原学习数据。
2. 打开“文件”App，在“浏览”中查找“下载”文件夹；没找到时，回 Safari 查看下载按钮所显示的状态。来源：[Apple：查找下载的文件](https://support.apple.com/zh-cn/guide/iphone/iphc9cd7266c/ios)。
3. 核对下载位置：当前手册给出的入口为“设置”→“App”→“Safari 浏览器”→“下载”，可以选择本机、iCloud 云盘或其他位置。按实际配置在“文件”中查找，不假定所有下载都在同一目录。来源：[Apple：Safari 下载位置设置](https://support.apple.com/zh-cn/guide/iphone/-iphb3100d149/ios)。
4. 确认看得到预期文件名、文件不是空的，并能被选取；再通过应用的恢复预览校验，阅读数量与警告后取消即可，不必为了验证文件先清空原数据。

找到文件、通过预览、实际恢复成功是三个不同结果。预览取消不会写入；真实恢复应单独按[备份与恢复说明](./3.0-local-data-and-backup.md)操作。不要公开发送包含练习正文的备份文件。

## 真机验收清单

请分别记录 Safari 和主屏幕两种入口的实际结果。未做的项目写“未验证”，不要默认通过。

|检查|操作与通过条件|当前结果|
|---|---|---|
|页面与返回|练习→报告→返回；新建与继续入口正确，五栏不散开、等级标识正确|未验证|
|文字与键盘|输入长句、放大文字、横竖屏切换；输入框、保存和返回仍可操作，无遮挡|未验证|
|选择与滚动|长按单词、调整选区、复制、上下滚动；记录按钮也可完成保存|未验证|
|录音与打断|短录音回听、拒绝权限、切换 App 后返回；状态可理解、不重复提交或遗留录音|未验证|
|朗读能力|有确认的本地英语音色则可播放，无音色则明确提示；不暗中使用远程音色|未验证|
|离线闭环|先确认页面与所选资料就绪，再主动断网；新建练习、记录、复习及刷新恢复分别检查|未验证|
|数据与重复操作|刷新、再次打开报告、重复恢复预览不应改变积分；备注与词句仍可找到|未验证|
|文件与恢复|本机找到导出文件、恢复预览通过；不删除真实数据验证，不把预览当实际恢复|未验证|

断网测试应在不影响电话或重要网络事务的合适时机由你操作，完成后恢复网络。Safari 与主屏幕入口的数据不能假定自动相同；安装也不保证浏览器永不回收数据，仍需备份。相关边界见[已查证的 iPhone 存储说明](../research/2026-09-09-iphone-selection-storage.md)。

电脑上的 Chromium 或 Windows WebKit 测试不能替代以上真机结果。特别是“关闭本地测试服务器”与“iPhone 实际断开网络”不是同一测试条件；即使前者能从缓存继续学习，表中离线项目也仍应由你在手机上验证。没有下载过的类别可能需要先恢复联网准备，不以反复刷新或清除记录解决。
