# 本地数据与备份说明

状态：3.0 使用说明草稿；对应功能仍在开发，正式发布前需按最终界面和实际测试结果复核。

iPhone 的主屏幕安装、下载文件查找及非破坏性自查步骤见[安装与自查指南](./3.0-iphone-setup-and-checks.md)。

## 数据保存在什么地方

练习文字、记录簿、任务和积分保存在当前设备的浏览器存储中，不依赖电脑或 MySQL。不同设备不会自动同步；更换浏览器或访问不同网站地址，也不能假定会出现相同的记录。

录音仅供当前练习回听，离开后释放，不放入长期备份。本地积分用于自我激励，不具有现金价值或真实好友排名证明能力。

添加到 iPhone 主屏幕并不等于永久保存数据；WebKit 对存储配额、回收和持久存储请求有单独规则，用户清理数据也仍然会影响记录。[WebKit 存储策略](https://webkit.org/blog/14403/updates-to-storage-policy/) 因此在 Safari 与主屏幕入口之间切换时，应先确认实际可见的记录，不假定两者自动共享或迁移。

## 建议什么时候备份

- 定期备份，尤其是在准备清理浏览器数据、更换设备或处理存储空间不足之前。
- 导出后，实际检查下载文件是否已经保存，不要仅凭页面提示就清理原数据。
- “最近生成导出”只能说明应用生成或请求下载了文件，不能证明文件已经保存成功；确认文件可找到、可读取后，再把它作为自己的备份。
- 备份包含个人练习内容，请自行妥善保管，不要公开上传或发送给不必要的接收方。

## 导出与恢复

1. 在“我的”的数据管理区域选择导出，将 JSON 文件保存到自己可找到的位置。
2. 在目标设备打开 SpeakMate，选择恢复备份并选取该文件。
3. 阅读校验结果、记录数量、将新增或更新的内容，以及任何冲突和警告。
4. 明确确认后才开始写入；取消预览不会改动本机数据。
5. 恢复后检查等级、练习历史、记录簿和积分账本。重复恢复相同文件不会再次发奖。

恢复是合并，不是默认覆盖全部数据；较新的本机记录和删除状态可能优先保留。若备份与当前本机身份或不可变事件冲突，系统应解释原因并拒绝有风险的合并，而非擅自混合数据。原始备份文件保留不变。

首次在新设备打开时，系统会产生一个本地访客身份。如果这个访客尚无学习记录，恢复预览可以明确告知并采用备份中的原身份；若两个设备已经各自积累了不同身份的学习记录，本版不自动把它们混成一套。请先分别导出保留两份数据，不要为了强行合并而清除任何一方。

删除来源对话不应删除已保存词句的上下文副本，也不应撤销已经真实完成任务的积分。恢复时会验证账本与学习事件的关联，而不是只读取某个“余额”数字；同一任务再次练习可以留下新练习记录，但不能再次获得同一任务奖励。

“可以恢复这份备份”与“其中每一段对话都能继续”不是同一件事。合法的旧版或无法完整恢复练习状态的记录可以作为历史保留；应用应说明不能续练的原因，并允许另开新一轮，不擅自补造对话或奖励。格式损坏、版本不支持等校验失败则会在写入前拒绝，并保留原文件和本机数据。

少数旧记录的内部编号可能不适合新版页面链接，例如特别长或包含非英文字符的编号。这不表示记录丢失或备份无效：应用应在原页提供完整的只读查看和导出入口，并说明无法直接链接或按该链接续练。若要重新练习，需明确另开新一轮；原编号、原文和关联记录保持不变。不要为修复链接而手动修改备份中的编号。

## 遇到问题时

|提示或现象|处理方式|
|---|---|
|其他页面阻挡升级|先结束并关闭其他 SpeakMate 页面，再重试；不要清空数据|
|文件损坏、格式不支持或关联缺失|保留原文件和本机记录，选择另一份完整备份；不要手动修改余额来绕过校验|
|备份超过大小限制|保留已有记录和文件，不反复强行导入；根据明确错误说明处理|
|本机空间不足或写入失败|本次恢复不能留下半套数据；腾出空间后重试，并保留备份|
|换设备后看不到原记录|确认使用预期网址和浏览器；本版需要通过备份文件迁移，不会自动同步|

浏览器可能因用户清理或存储回收而移除本地数据。备份提醒不能保证数据永远不会丢失；下载、录音、本地音色和 PWA 行为仍需在自己的 iPhone 上确认。
