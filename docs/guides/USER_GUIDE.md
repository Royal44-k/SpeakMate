# SpeakMate 3.0 使用教程

适用：本次 3.0 源码及候选部署。确认访问版本后操作；不要仅凭旧网址推断已更新。应用是 PWA，不需要微信账号、苹果开发者账号或 MySQL。

## 1. 初次设置

打开应用后在“目标”完成欢迎指导，选择 A1–C1 等级、兴趣和每日 5/10/15 分钟目标。不确定时可从较容易的等级开始；这不是分级考试。以后可在设置中调整，已开始的任务与对话保留当时等级，新的自由练习采用新的个人等级。

五个底部导航始终按“目标、练习、场景、记录簿、我的”排列。页面内返回用于回到来源，底部导航用于切换大板块；不要用清空浏览器数据处理返回问题。

## 2. 完成一天的计划

1. 在“目标”查看表达热身、场景应用和巩固练习。15 分钟计划另有可选拓展。
2. 点击每张任务卡直接进入对应流程；没有笔记时，热身使用当前等级的入门表达。
3. 未开始任务可换一次。刷新不会重新抽取，修改时长不会抹掉已完成任务。
4. 场景任务按卡片指定条件完成并确认结束；仅进入页面、反复打开报告或只点帮助不等于完成。
5. 完成任一学习任务自动打卡。每个核心任务 10 分，三项全完成额外 5 分；可选拓展 10 分。同一任务仅结算一次。

时间为安排参考，不必挂机凑分钟。打卡按北京时间；跨日可以继续旧任务，完成事件只结算一次。中断连续学习不扣分。

## 3. 自由场景对话

1. “场景”输入中文或英文关键词，使用搜索按钮；用 × 清空。结合分类、等级和长度筛选。
2. 进入准备页，核对角色、背景事实、难度与预计轮数：短练约 3 轮、标准约 6 轮、拓展约 10 轮。
3. 点新练习开一轮。想接着说则从“练习”的继续入口恢复；新一轮不会覆盖旧记录。
4. 优先自己作答，再展开当前问题的参考表达。录音停止后可回听；没有确认可用的端侧识别时，需手动填写或核对文字再提交。
5. 可以请求澄清、表示表达困难或调整选择。词句未匹配不代表说错；未收录内容不会获得虚构语法分析。
6. 自然结束后确认完成，查看本轮反馈与复盘。停止练习是主动放弃，不等同完成任务；普通暂时返回保留进度。

健康、求助、购物等均为虚构语言训练，应用不会替你救援、诊断、预约、付款或联系商家。无需提供真实地址、病历和证件。

## 4. 把有用表达存进记录簿

- 在对话、历史、参考表达或反馈中点“记录”；可以保存整句，或利用原生长按/选区选择词句。
- 保存前核对原文、场景来源与上下文。保存后可“查看”或“撤销”，也可继续对话。
- 同一标准化词句合并来源，不重复堆卡片。在“记录簿”搜索、分类、加标签/备注、编辑或删除。
- 已覆盖资料可看释义、搭配、结构、语体与例句。部分覆盖只解释对应部分；尚未覆盖时保留原文和个人备注，不假装理解整句。
- 删除原练习不应删除笔记已保存的上下文副本；不同场景下同一表达的意思需按所选来源查看。

## 5. 复习和模拟

在“待复习”遮盖后回忆，再用“记得／模糊／忘记”自评。默认间隔是产品安排，不是对每个人最优的记忆算法。已覆盖内容可进入“回忆 → 替换或造句 → 情境应用”，结束后回到原笔记或任务。未覆盖表达只提供自我回忆、备注、可用时本地朗读等能力，不会伪装完成语义评分。

## 6. 奖励与我的

积分分为累计获得和可兑换余额。数字奖励包括个人卡样式、目标卡封面和随身资料；兑换后应用样式或查看内容。没有实物、现金、地址、物流和转赠。示例好友榜与真实个人分数分开，不是真实好友数据。

“我的”可查看历史、统计、设置与数据管理。自动播放、语速及反馈设置影响练习入口；本地音色是否存在依赖设备。

## 7. 备份、安装和断网

请阅读 [iPhone 安装](3.0-iphone-setup-and-checks.md)和[备份指南](3.0-local-data-and-backup.md)。导出后确认 JSON 已保存在设备，再在恢复预览中检查数量；不要为试恢复先删除原数据。备份上限 10 MiB，不包含录音；不同设备和不同网址不自动共享记录。

首次使用与未下载过的内容需要网络。等页面和所选内容都准备好再尝试断网；浏览器标为离线、Windows WebKit 测试和真实 iPhone 飞行模式是不同条件。

## 8. 常见问题

| 问题 | 可以怎么做 |
| --- | --- |
| 新网址没有旧笔记 | 确认域名、浏览器与主屏入口；先保留旧入口并导出，不清数据 |
| 麦克风拒绝或没有音色 | 按页面提示检查权限；仍可使用文字回答，不需要购买云语音 |
| 回答未覆盖 | 查看当前参考表达或先记录个人句子；不是系统认定你错了 |
| 积分没有重复增加 | 同一任务只奖励一次，普通自由练习并非自动绑定每日任务 |
| 数据库升级被阻挡 | 关闭其他 SpeakMate 标签页后重试；不要清空站点 |
| 页面打不开 | 先分清网络、域名、缓存与应用错误；记录提示，MySQL 无法解决网站连通性 |

报告问题时附版本、设备/系统、入口、操作步骤和去隐私截图。不要在公开 Issue 上传录音、个人备份或完整私人对话。
