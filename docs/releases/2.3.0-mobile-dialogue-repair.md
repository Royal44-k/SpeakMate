# SpeakMate 2.3.0：移动布局与对话体验修复

更新日期：2026-09-09。依据用户提供的咖啡点单 C1 链接及首页截图；延续深蓝、珊瑚色、纸白的既定视觉。执行计划：`docs/plans/2026-09-09-mobile-dialogue-repair.md`。

## 开发约束与实现

1. **统一手机画布**：所有页面的根内容最大宽度 480 CSS px，宽屏居中；固定导航、录音、输入、处理和结束栏对齐该宽度。详情退出后不再展开为桌面布局。保留横向筛选和页面纵向滚动，避免通过隐藏溢出来掩盖布局问题。
2. **首页层级**：修复同时命中图片 span 与徽章的宽泛 CSS 选择器；图片保持实际高度，徽章独立定位在图片内。中文标题改为合理字号和行距。存在进行中会话时，先呈现“开启新一轮对话”，再呈现“继续本次对话”。
3. **水平一致性**：首页选择器显示当前档案水平。场景库明确点击水平后持久化到档案；URL 仍保留本次筛选、搜索及返回来源。旧对话保持其原等级，首页明确标注，不因更改当前水平而改写历史。
4. **可操作搜索**：右侧搜索按钮、独立 X 清空、回车和手机搜索键；清空后焦点回到输入框，保留其他筛选。支持中文输入法组合、即时结果、中文同义词、中英多词交集、全角和标点归一化、英文单字符拼写容错。匹配标题、背景、角色、目标、所有等级关键词和表达；标题匹配优先。按钮至少 44px，操作区间距 8px。
5. **场景语料**：42 场景 × 3 个任务主题；每个主题 3 个情境问题、3 个分层回答，共 378 个问题与 378 个回答条目。按 A1–C1 约束选取短问、追问或带条件/取舍的挑战；这些是人工编排语料，不宣称 756 个独立场景或无限生成内容。
6. **逐轮推进**：结合已完成目标和完整的本场练习上下文选取未说过的问题；当前会话内去重；新会话轮换开场并据此改变追问顺序。不能因轮数增加就自动标记任务成功。本地目标判断仍是关键词规则，并非语义能力测评。
7. **下一句支持**：在当前回复之后提供可展开的“下一句怎么说”，按当前任务呈现简短回应、自然表达、进阶拓展；按当前等级安排顺序，排除已逐字练过的答案。不自动代填、不替用户提交；云端自由回复时这些是任务表达参考，用户仍需根据对方的问题调整。
8. **新建与恢复**：`/session/new` 始终创建独立记录；初始化去重，成功后将当前历史条目替换为真实 `/session/session_*` 地址，不增加虚假返回层级。存储开场、每轮完整反馈、任务进度及回复提示；刷新恢复本场而非隐式寻找其他会话。旧版记录兼容原有字段。
9. **明确结束**：目标完成、教练建议结束、剩余题库耗尽或达到本场上限后进入复盘入口；不再重复询问结束语。完成页提供查看复盘及再练一轮，新一轮通过来源记录标记确保组件重新初始化，不需要刷新浏览器。客户端防重复提交，API 校验轮次上限；不可重试/安全/额度错误不再被本地降级静默绕过。限流失败后仍可编辑草稿再提交，无声录音保护不会因编辑而失效。
10. **接口与安全**：会话上下文上限由 8 条改为 40 条（最大 20 个用户轮次），单条仍有长度限制；云端重复回复触发受控失败或既有 auto 模式降级。校正 Next 内部 hostname 与实际 Host 不同导致的正常同源提交 403，继续校验协议、Host 和 `Sec-Fetch-Site`，不信任任意转发域名。不引入收费资源、登录要求或额外数据上传。
11. **更新与隐私**：版本及离线壳缓存同步到 2.3.0。正常应用更新不删除 IndexedDB 练习记录；缓存更新仍遵循现有“有草稿/正在录音时不强制刷新”的规则。测试产物不上传部署包。

## 尼尔森十大原则核对

| 原则 | 本次落实 |
| --- | --- |
| 状态可见 | 当前与原对话等级、轮次、下一步任务、处理与结束状态 |
| 贴近真实世界 | 咖啡口味/替代奶/取餐，酒店房型/设施等场景专属追问 |
| 用户控制 | 明确新建或继续、退出保护、清空搜索、保留旧记录 |
| 一致性 | 全路由手机宽度、固定栏对齐、统一触摸目标 |
| 预防错误 | 初始化/提交去重、结束后不再发第七轮、同源防护 |
| 识别而非回忆 | 当前问题下的中文提示及分层回应参考 |
| 效率 | 多关键词、同义词、回车搜索、恢复原地址和筛选 |
| 简洁美观 | 缩小中文标题、图片与徽章分离、参考表达渐进展开 |
| 错误恢复 | 失败保留草稿，刷新还原结果，存储异常给出说明 |
| 帮助 | 基础反馈能力说明，不伪造完整语法或发音评分 |

## 用户更新与复验

1. 先保存或完成当前练习，回首页；出现“新版本已准备好”时点“立即更新”。若尚未提示，可在网络通畅时关闭后重开或刷新页面，勿为更新而清除网站数据。
2. 首页切换等级，核对“新一轮”使用当前等级，而“继续”保留原会话等级；从继续对话退出，确认仍是手机宽度。
3. 在场景库搜索“拿铁”，点搜索，再点 X；确认出现咖啡场景且清空后保留等级筛选。
4. 开启新一轮，展开“下一句怎么说”，连续练习、查看复盘，再直接开启下一轮；旧记录应仍可在学习中心访问。
