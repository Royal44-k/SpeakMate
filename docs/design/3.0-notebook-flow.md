# 记录簿交互实施说明

状态：3.0 已批准范围的实现细化；页面尚未交付或视觉验收。数据端口以 Task2 实现为准，解析与对话端口以最终 Task3 报告为准。

## 设计基调

沿用现有 Dialogue Stage，不另起一套主题。Atlantic `#0B2A43` 用于主要文字和练习舞台，Coral `#FF6B5E` 用于当前主要动作，Sky `#DDEFFD` 用于轻量提示，Paper `#FFFDF8` 用于页面，Ink `#14202B` 用于正文。英文展示沿用 Barlow Condensed，中文说明与长句沿用系统正文栈；不用窄英文展示字体挤压中文标题。

记录簿的识别特征是可阅读、可练习的“词句页”：原文居前，来源清楚，解析有层次。任务进度才使用步骤序号，普通笔记不加无意义的编号。列表避免把标签、来源、状态和操作都堆在标题一行；小屏允许自然增高。延续既有图标库与圆角，不新增插画依赖。

## 一级结构与页面职责

|区域|主要内容|当前主要动作|
|---|---|---|
|词句|本地搜索、词／短语／整句筛选、笔记列表|打开一条词句；空列表引导进入场景|
|待复习|到期数量、逐条回忆、自评结果|回忆后查看答案，再选择记忆状态|
|模拟练习|可继续的练习、从词句选择目标表达|继续已有练习，或选择词句新建|
|词句详情|原文、覆盖状态、释义／用法、例句、个人备注、来源|根据覆盖范围进入对应练习|

三个板块不是新增底部导航；底部仍遵循全应用五项顺序。列表搜索仅在本机保存，页面路径不能包含搜索或笔记正文。选中词句、筛选和滚动恢复复用现有导航结构，不由各页建立相互竞争的全局监听。

## 从练习中记录

1. 在双方对话历史、参考表达、反馈或复盘中，选择文本或点击可见的“记录”。该按钮保存整句或打开选词界面，不依赖原生选区是否可读取。
2. 预览显示待存原文、类型和来源。用户能直接修改待存文本、取消或保存；选词方式支持逐词点选与键盘操作，不要求拖动。
3. 原始选区只限于当前文本块。不要把多个卡片、按钮标签或中文界面说明意外拼进英文记录。点击记录时先保存选区快照，不能因按钮获得焦点而丢失选择。
4. 保存成功留在原练习，显示“已记录”以及“查看／撤销”。写入失败保留预览和输入，不显示成功，不清空原对话。
5. 相同标准化词句提示“已存在，已补充来源”，使用仓库返回的主记录 ID；不能盲目使用新建 ID 打开不存在的详情。重复内容的撤销应只撤销本次变更，不删除之前已存在的整条笔记或其复习记录。

一次保存的变更凭据与结果须足以执行准确撤销。若来源在其他标签页已变化，先读取最新状态并避免覆盖他人的后续修改；发生冲突时解释原因，不以删除整条记录实现“撤销成功”。

### 每个文本块的题目来源

同一话轮不一定只涉及一个问题：用户刚回答上一问，对方回复可能已进入下一问。来源应绑定到实际被记录的文本块，而不是整轮共用页面当前的问题标识。

|记录对象|应保留的题目上下文|
|---|---|
|用户回答、对应参考表达与针对该回答的反馈|提交前的被回答问题；主动改主意时为明确选择的旧问题|
|开场问题或对方提出的下一问|该问题自身的标识，通常分别来自创建结果或推进后的状态|
|澄清提示、混合回复、结束语|仅在能明确归属的独立文本块上附题目标识；混合或无对应问题时不补造标识|
|历史记录|该次发生时的语境；不可统一使用现在最后一问，也不向旧版缺失记录虚构来源|

历史上下文应从已验证的固定快照与该次输入恢复，或使用同样经过校验的已保存信息。复盘引用某句表达时沿用那句的来源。无法唯一归属的文本仍能记录，但不得为了得到“完整解析”借用邻近问题的语境；相关呈现接口由对话整合阶段统一提供，记录簿不另写一套对话引擎。

## 详情与解析

原文、校审资料和个人备注是三种不同来源，视觉上分区并有文字标签。完整覆盖展示适用语境与版本；部分覆盖只解释实际匹配片段；未覆盖说明“当前本地资料未收录”，保留备注、自我回忆和可用的本地跟读。没有匹配到错误不等于语法正确或表达优秀，不显示未经证明的评分。

释义、搭配／结构、正式程度、常见错点与例句采用逐层展开，首屏先让用户理解这句话有什么用。展开不强制跳到页面顶部；有加载或失败状态时保持原文可读。

删除练习来源后，笔记仍显示保存时的上下文副本；来源链接不可用时说明“原练习已删除”，而非跳转后才显示空白。手动编辑原文后重新判断覆盖状态，不能保留上一句话的“完整解析”标签。

同一词句合并后可能拥有不同场景来源。详情须明确标出当前解析所用的来源；当有多个来源时，用户可以选择查看的语境，而不是把第一条来源或最近一次解析当作所有来源的共同含义。从所选解释进入模拟时保留这一来源；手动记录或旧收藏缺少语境时如实显示覆盖限制，不借用无关场景补成完整解析。切换来源不复制出重复笔记，也不覆盖个人备注。

## 复习与模拟

复习先遮盖答案，再由用户主动揭示，随后选择“记得／模糊／忘记”。这些是自评，不是系统测出的掌握率。新复习基于当前最新复习记录推进；另一标签页已提交时重新载入，不覆盖旧链或重复发奖。

有覆盖的模拟包含回忆、替换／造句及 3–5 轮情境应用。每一步均有可见进度和继续／退出方式；填入参考句只是编辑输入，不自动认定练习完成。目标表达来自本机记录与已校审内容，不能随机拼接看似相关的对话。

模拟刷新后恢复真实步骤、来源笔记和任务归属；新会话的临时 ID 替换保留返回信息。提交结束后不出现下一句提问，显示本次结果和“返回原词句／返回复习队列”。从目标任务进入时也保留原任务日期，避免跨日改归属。

### 定向应用路径（实施决策 22）

普通场景的短练、标准、拓展路径不一定包含保存的表达，因此不能只把“同场景短练”改名为定向练习。增加有限、明确编写且独立版本化的微练习描述，关联已有解析条目、实际来源等级和适用题目／意图；每条描述规定完整的 3–5 问路径、来源变体／情境和适当结束语。描述随已有公开分类资料下载，解析和创建仍在本机，不增加接口服务或把笔记文字放入请求。

当前盘点为 57 个解析条目、277 组有效的“条目 × 来源等级”关联：餐饮 101、职场 26，其余五类各 30。超市 show 句型仅关联 A1，会议 test-assumption 整句仅关联 C1；不得按 57 × 5 凑数，也不按用户后来修改的等级重新标记来源。该盘点是待实现覆盖清单，不是路径已编写或已审查的证明。现有支持关联应全部提供可用的校审路径，而不是缩成少量演示；同组多个目标若不能在 3–5 问及必要前提内同时覆盖，应按实际源题拆分并说明，不任意删除前提、增加轮数或把已支持内容永久降成自练。确有无法成立的关联，应先提出具体内容缺口再调整方案。

仅在创建新模拟时，由描述和原资料生成新的固定练习快照，沿用现有引擎；普通语料包、普通 3／6／10 轮选择和所有已保存快照不变。微练习只展示其实际路径和轮数；内部兼容现有模式字段不等于向用户提供三个不同长度。固定来源语料版本与微练习描述 ID／版本，并对来源题目、依赖、完整路径和备份往返进行严格有界校验；恢复不按今天的描述重建旧模拟。不增加第二套通用对话引擎。

路径的审查单位是完整组合：逐项阅读所有题目及两种答案、所选情境、事实依赖／分支和结束语；已读过原题不能自动证明任意重排或切片自然。相同来源等级、变体和完全相同路径可以共享一次实际阅读记录，但不同解析条目的目标覆盖仍须分别校验；不得由自动生成器直接标记通过。原文仅部分匹配时，先明确所练的是哪个已覆盖片段，不能宣称整段都被解析；真正未知、来源关联缺失或资料暂不可用时显示相应边界与自我练习／重试入口。

### 进度与来源身份（实施决策 23）

在现有 PracticeSession 上增加可选、独立版本且有界的模拟来源／进度信息，不新增模拟数据库或第二个流程引擎。固定规范笔记 ID、所选来源 ID 和上下文副本、原文类型、合法返回位置，以及微练习描述的来源版本。保存真正完成的回忆、造句输入与时间；情境应用仍使用现有固定对话快照和话轮。现有完成证据与完成时间保持权威，不另存一套可以互相矛盾的完成结果。备份须同时验证来源、阶段顺序、时间与实际话轮；旧数据没有这些字段时不被改写。

来源编号只在同一笔记内保证唯一，不能跨记录簿按来源编号找“第一条匹配”。已有详情选定来源后，先在本机完成受保护的创建，再跳到真实模拟记录 ID；这样特殊旧笔记／来源编号也不用塞进新版 URL。直接进入新建入口时，source 参数解释为规范笔记 ID，展示并确认其真实来源选择，不能把相同来源编号的另一条笔记混入。多个来源必须保留用户所选语境；缺失、歧义或已删除的来源提供明确恢复入口，不猜测。来源正文和上下文仍只存本机。

模拟的回忆、造句、推进、停止与确认由既有受保护仓库处理；普通会话写入口不能绕过前置步骤或把模拟当作普通场景提前完成。首页、历史、恢复与结果入口应识别模拟类型并进入正确页面。完成的原子事务继续为后续任务／积分结算提供唯一接入点，不预先写空奖励事件等待补发。

未覆盖原文只保留保存、自我回忆、个人备注和可用的本地跟读。不能给未知内容增加伪装成情境应用的自由输入轮次，也不能据此生成模拟完成证据。自评复习与有覆盖的完整模拟分别呈现和记录。

### 目标题的含义补齐（实施决策 24）

独立审查发现五组有效关联虽然能走完流程，却缺少表达目标含义的参考回答：餐厅 on-the-side 的 A1／A2 只提供加或不加辣椒，no-chilli 的 B1／B2／C1 只提供混入或另放辣椒。“另放”不能替代“完全不加”。保持全部 277 组关联，不用相关但含义不同的题目冒充目标覆盖。

仅为这五个描述采用独立内容版本 2；保留描述 schemaVersion 1 和旧内容版本 1 的严格读取。版本 2 必须包含一项有界的 targetQuestionOverride，沿用现有完整题目结构，固定原目标题的 ID、意图、目标和前提，仅为新模拟提供明确校审的题文、中文提示、两种回答、接受写法及对应效果。效果仍属于原题的事实键，不能借此修改其他目标。版本 2 限于上述五组关联；其余 272 个描述保持版本 1。普通语料包、普通路径、原语料版本和已有快照不改写，不增加引擎、数据库或新下载端点。

新建时仍校验完整的原始十二问资料和所选描述，再在新快照中替换这一目标题。公开资料、临时创建材料和严格备份必须共同校验身份、版本、校审状态及实际投影内容；恢复旧快照不按新描述重建。新版本的回答须真正区分“另放／混入”或“省略／添加”，不能把不同含义记成相同结果或仅添加表面关键词。

每条修改后的完整路径都要重读全部题目、两种回答与接受写法、效果、情境和结束语，并补充实际目标回答的确认测试。统计相同路径时必须比较实际生效材料，不能因为题号相同就把修改前后的不同语言组合当成已读同一路径。自动遍历仍不能代替语言审查；教师审阅状态不因这次修复改变。

## 需由实现测试确认的边界

- 空记录簿、没有到期记录、未知表达、原来源被删、保存失败、撤销冲突和存储空间不足。
- 选词、整句按钮和键盘路径得到相同可保存结果；不劫持原生复制或滚动。
- 编辑后解析失配、重复保存来源合并、删除撤销、复习并发、模拟中断恢复。
- 离线新建的笔记和模拟记录可以立即打开，包括从未在线访问过的新标识。
- 320–430px、200% 文字、横屏与键盘弹起时按钮、焦点、错误及提示不被固定栏挡住。
