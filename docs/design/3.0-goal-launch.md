# SpeakMate 3.0 任务材料与启动契约

状态：2026-09-11 的实施决策 25–26，尚待实现和验证。补充 APP_SPEC、练习保存契约及任务验收案例；不改变零费用、本地运行或计分规则。

## 巩固任务的首次材料选择（决策 25）

没有可用笔记时，保存明确的 simulation-choice 待选择目标：它没有虚构笔记或轮数，不能标为已开始、完成或获得积分。计划卡仍说明本任务的目的、估计时间及选择入口。用户可选择真实笔记的可用来源；未知内容仍保留自己的记录与能力边界，不被别的内容悄悄替代。

也可明确选择“记录这条校审词句并用于任务”。这一步使用现有记录功能，展示真实原文和来源，按规范笔记身份去重。保存词句是一个真实动作，不等于练习完成。若之后启动失败，说明“词句已保存，练习尚未开始”，可重试；不能声称此前保存的笔记也已回滚或无故将它删除。

新任务的已绑定模拟目标保存一个有界版本 1 selection：规范 noteId、笔记内 sourceId、sourceLevel、descriptorId、descriptorVersion、sourceContentVersion，并记录从实际选定微练习读出的轮数。保留旧格式目标的备份读取；新的任务启动不可省略这些关系验证。

在既有 practice.commit 创建事务内，增加可选 taskLaunch（planId、taskId）上下文。事务读取最新计划与真实笔记／来源，用现有 simulationMaterial 验证新会话的完整固定资料；首次绑定目标、保存 started 与真实来源归属、保存会话一起提交，成功后才导航。首次绑定不消耗“换一项”机会，也不允许普通更新接口任意改写已固定目标。已开始或完成的目标不能被迟到选择覆盖；重试、两个窗口选择、旧快照提交及事务失败须有明确结果。

这不是独立绑定服务或通用事务接口，不新增存储表、引擎、自动生成解析或补发奖励。已完成的学习仍由原确认事务结算；仅选择、记录或启动均不发奖。

## 普通场景的实际路径（决策 26）

当前轻量场景目录只有等级与语料版本，不能证明某个具体变体的路径长度。补充由现有已校审普通语料提取、可与原包逐项核对的有限路径元数据：场景、来源等级、语料版本、真实变体 ID，以及各模式的实际提交上限。只含公开元数据，不带题文、答案、分析或用户资料。

元数据采用静态、客户端可用的有限清单；生成或提取只在开发／构建边界读取原语料，客户端不得因此导入全部正文。不新增下载端点、缓存管理器或数据库。校验覆盖当前全部普通分级包与变体，缺失、失配或过期时明确失败，不能退回猜测的全局轮数。

新场景任务保存有界版本 1 selection（level、mode、variantId、contentVersion），requiredUserTurns 取自该条实际路径元数据，而不是重复硬编码所有路径都是 3／6／10。创建前再与已验证公开资料中的实际路径核对；失配时保留原任务并提示资料状态，不偷偷换短路径或改写已开始目标。旧格式目标仍可读取，不能按今天的目录重写历史。

代价：增加小型公开元数据、目标版本与一致性验证；需要覆盖首次绑定、并发、失败、备份与历史兼容。若内容组织变动，应更新元数据并通过校验，不能绕过检查或把资料缺失当完成。
