# 场景网址标识与数据 ID

状态：从现有 `src/content/scenes/categories/*` 的种子顺序与 `factory.ts` 实际生成规则核对，用于 3.0 兼容性约束。它不表示新语料已完成。

`slug` 用于场景网址和内容目录名；`SceneDefinition.id` 用于会话、任务、笔记来源及备份关联，两者不能混用。例如 `/scenes/coffee-order` 对应的数据 ID 是 `dining-01`。新增内容包必须保留这对映射，不改旧 ID，不重排旧种子数组造成编号变化。

|类别|01|02|03|04|05|06|
|---|---|---|---|---|---|---|
|travel|airport-check-in|security-screening|flight-connection|immigration-interview|hotel-check-in|hotel-room-problem|
|dining|coffee-order|restaurant-order|food-allergy|return-item|supermarket-help|price-discount|
|daily|ask-directions|taxi-ride|bank-card-problem|collect-parcel|haircut-request|phone-repair|
|work|work-introduction|daily-standup|progress-update|deadline-negotiation|meeting-disagreement|job-interview|
|social|first-small-talk|networking-event|make-invitation|polite-refusal|discuss-opinions|apology-repair|
|study|class-introduction|ask-teacher|group-project|presentation-qa|seminar-discussion|office-hours|
|emergency|pharmacy-medicine|describe-symptoms|doctor-appointment|emergency-call|lost-property|rental-repair|

表内值是 slug；对应数据 ID 为“行首类别－列首编号”，例如 `restaurant-order` → `dining-02`、`rental-repair` → `emergency-06`。场景显示版本与语料内容版本各有含义，不能互相代替。

测试应使用手工核对的 ID／slug 对和旧备份验证，不能由待测的新映射同时生成输入与预期结果。来源删除后仍须保留笔记快照；合法历史场景版本也不能因为当前目录更新而被拒绝。
