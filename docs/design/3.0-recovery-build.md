# SpeakMate 3.0 只读兼容回退契约

状态：2026-09-11 选定方案，尚未实现和验收；对应实施决策 2、29。它是故障时保留和导出数据的应急构建，不是功能完整的 2.3 复刻。

## 入口与构建边界

- 在现有 Next.js 项目增加一个固定 `/recovery` 页面；正常构建和应急构建都只提供读取、导出及必要的恢复指引，不挂载普通学习页面、完整仓库、数据管理写操作、导航协调器或自动更新消费者。
- `/recovery` 不加入离线页面外壳清单。当前旧工作线程对未知规范路径透传网络；须以真实受控页面验证这一入口，不能把清空浏览器缓存或强制刷新当作切换方案。
- 应急构建使用构建期固定的 `NEXT_PUBLIC_RECOVERY_ONLY=true`，根布局不渲染普通页面子树。验证根路径、全部既有深链、旧链接及查询形式均不能挂载学习写入消费者；普通构建行为保持不变。缺失路径、错误边界和跳转也不能意外开启学习。
- 应急构建有不同的构建标识，健康接口和可见界面明确只读恢复模式。最终正常构建与应急构建分别留存和验收，不靠发布后临时修改源码获得回退能力。

## 本地数据边界

- 只接受已经存在、版本恰好为 2 且具备全部 12 个存储区的数据库。无库、v1、较新版本或缺少存储区时，明确拒绝；遇到建库／升级事件直接中止，不能隐性创建、迁移或降级。
- 复用原存储读取循环并注入只读打开器，暴露 `Pick<LocalStoragePort, 'read'>`。事务只能为 `readonly`，读取结束关闭连接；不调用普通会升级的 `getDatabase`，不暴露 `change`、导入、删除、初始化身份或奖励写入。
- 从原备份端口提取并复用同一个完整导出函数与校验逻辑，不另建序列化格式。导出含原 schema 2 的全部支持数据，保留 10 MiB 限制，超限或校验失败必须明确报错，不能截断后称成功。
- 只读恢复不提供练习、继续会话、编辑、恢复导入、清除或兑换。用户已打开的旧学习页不因此自动变成只读。

## 旧工作线程的安全退出

- 仅用户明确点击后注销本应用自己的注册：作用域精确为当前源 `/`，已有 active／waiting／installing 的脚本地址均精确为当前源 `/sw.js`。未知注册保留并说明，不批量注销其他注册，不删除缓存或 IndexedDB。
- 注销返回值、当前页面控制器和可继续状态分别呈现。注销成功不能当作当前页面已脱离旧控制器的证据；注册还可能被其他页面重新建立。[MDN 注销说明](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerRegistration/unregister)
- 失败、拒绝、仍受控制时，恢复界面自身仍只读；明确指引用户关闭所有 SpeakMate 标签页和已安装 PWA 窗口，再联网打开固定恢复入口。不得自动循环刷新、强制关闭用户窗口或宣称其他旧页已被保护。
- 只有真实检查确认没有旧控制器时才显示相应就绪状态；此状态不等同于能证明没有任何其他旧窗口。首次切换需要网络，不保证断网时可进入应急构建。

## 必须留下的证据

在同一隔离测试源下：原始 v1 固定样本 → 正常 3.0 升级 → 真实练习／记录／事件 → 全部 12 存储区快照 → 切换已构建应急服务 → 经旧控制器打开 `/recovery` → 明确注销并关闭测试窗口后重新打开 → 读取和下载 → 检查实际文件并与原数据比较。覆盖根路径及全部深链、无库／v1／较新版本／损坏状态拒绝，验证数据库版本及所有存储区没有变化。

测试只处理合成数据，不修改日常浏览器记录、设备时间或正式部署。模拟 WebKit 不能证明实体 iPhone 已通过；应急模式的功能限制、网络前提和超限导出限制必须在最终交付中说明。
