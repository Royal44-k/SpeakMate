# SpeakMate 2.3 修复计划

依据：用户 2026-09-09 的咖啡点单 C1 链接与首页截图。沿用深蓝 #0b2a43、珊瑚 #ff6b5e、纸白 #fffdf8 的视觉；中文采用正文无衬线字体与足够行距，英文舞台保留 Barlow Condensed。

## 复现与根因

- 首页 `.image > span` 同时命中 SceneImage 的 span 根节点和徽章，绝对定位导致图片塌陷、徽章覆盖正文；舞台存在同类选择器。
- 场景详情未使用 AppShell，也没有全局内容宽度边界；宽屏退出舞台后详情展开。480–540px 的舞台与固定输入区还存在断点不一致。
- 首页等级优先取未完成会话，而非当前学习设置；场景库水平选择只写 URL。
- `/session/new` 会查找并复用旧会话；刷新恢复靠复用这一隐式机制，缺少可寻址的新会话。
- 本地教练以单个关键词套用固定追问，缺少场景轮次语料和历史去重；恢复后缺少结束/反馈状态；到轮次上限仍可录音提交且前端会绕过 API 上限降级。
- 搜索仅匹配当前等级关键词的连续子串，没有搜索/清空操作，对同义词与多词查询支持不足。

## 执行步骤与验收

1. 添加原问题回归：详情返回后的宽度、图片实际高度/遮挡、等级与新建/继续动作、搜索、重复追问。
2. 统一根布局宽度（最大480px），修复图片与徽章的独立样式、中文标题行距、480–540px 固定输入栏对齐。首页先显示新练习入口，再显示带原等级的继续练习卡；当前水平可直接选择。
3. 搜索增加显式搜索按钮、清除X、回车/手机搜索键、输入法组合处理；保留即时结果、URL与筛选；扩大中英字段、别名、标点标准化及多词匹配。
4. 为42场景补充目标相关的轮次语料和回答支架，按A1–C1分层选择，结合历史避免原句重复；新场次轮换开场和表达。展示下一步目标及可切换的参考回答，不自动代填或提交。
5. 新建始终创建独立记录，刷新通过真实会话ID恢复；保留旧会话、轮次、目标与反馈。结束时提供复盘与另开一轮，禁止越过轮次上限重复提交。
6. 更新规格与版本/缓存，跑单元、生产构建、Chromium/WebKit和真实生产构建的导航循环、窄屏/宽屏/横屏几何验收；用IAB检查修复后截图，部署Vercel并记录线上验证范围。

## 尼尔森原则落实

状态可见：当前水平/原会话水平、当前目标、处理/结束反馈；贴近真实世界：场景专属问题与回答；用户控制：搜索清空、新建或继续、可返回；一致性：所有路由共享手机宽度与触摸目标；防错：新建不覆盖旧记录、终轮禁止再发；减轻记忆：下一句支架；效率：搜索别名与回车；简洁：适当标题比例与无重叠徽章；错误恢复：保留草稿/恢复会话；帮助：逐轮中文提示与明确基础模式边界。

## 约束

本地模式是有边界的脚本陪练，不冒充开放式生成AI或声学评分。既有云端提供方继续可配置；不引入收费依赖。线上链接在当前网络首次打开超时，公开内容验收以实际结果为准。
