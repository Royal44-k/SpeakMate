## 如何查旧版本

```bash
git log --all --oneline --reverse
git show deb7e0d:APP_SPEC.md
git show aacbffd:README.md
git diff aacbffd c2af548 -- src
```

只读历史不改变现有目录。确需运行旧版时另建隔离目录和独立浏览器来源；旧 2.x 可能有不同云服务默认策略，不能接触已升级的真实学习库，也不能作为当前免费/隐私承诺的依据。
