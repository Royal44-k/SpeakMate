# SpeakMate / 口语搭子

面向 A1–C1 学习者的移动端英语口语 PWA。3.0 的目标是“设定目标 → 完成练习 → 记录词句 → 理解表达 → 定向复习 → 获得奖励”。

**当前分支正在开发 3.0，尚未完成验收或发布。** 现有生产站点保留 2.3；开发分支的 `package.json`、manifest 和健康接口版本将在最终审查前统一更新。代码存在、草稿编写完成、单元测试通过都不等于手机或生产验收通过。实际阶段状态和测试所属提交见[3.0 验证与发布记录](docs/releases/3.0.0-verification.md)。

## 本地运行

按项目声明使用 Node.js **22.x** 和 pnpm **11.19.0**。确认实际测试与构建运行时，不只看系统或包管理器的默认版本。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

浏览器访问 `http://localhost:3000`。这只启动当前代码，不代表未完成的 3.0 页面已经可用。开发前先阅读 [APP_SPEC.md](APP_SPEC.md)、[实施计划](docs/superpowers/plans/2026-09-09-speakmate-3.md) 和仓库 `AGENTS.md`。

## 本版边界

- 严格零新增费用、设备本地学习。不启用订阅、MySQL、云数据库、云模型、远程语音识别或账号同步；已有适配器只是未来扩展边界，不是本版可开启的功能。
- 无需注册；练习正文、录音、笔记、任务和积分不上传。公开内容与页面资源仍需首次下载，离线准备完成与设备本地语音能力分别判断。
- 无法证明本地识别可用时采用录音回听＋文字确认；朗读只选择明确标为本地的英语音色，不暗中转云端。
- 本地助手只解释已收录内容，部分或未覆盖明确说明；不提供通用语义判断、音素评分或教师认证。
- 本地数据不自动跨设备同步，清除浏览器数据或设备回收可能导致丢失；需提供导出与恢复。积分仅用于自我激励，好友榜为明确标注的示例。

## 3.0 手机交互目标（待完整接入与验收）

- 五项导航依次为“目标、练习、场景、记录簿、我的”，先完成真实目的地，再统一切换导航。
- 手机内容最大 480px，操作目标 44px，适配安全区、键盘、横屏与 200% 文字；“随时开口”保持完整短语。
- 场景和记录簿的搜索文字只保存在本机；公开分类、等级、时长可作为网址选项。返回保留本地筛选、来源和滚动，不把私密搜索嵌入链接。
- 固定客户端详情页支持断网后新建记录；跨页面外壳采用明确的文档导航与退出保护。具体规则见[离线路由契约](docs/design/3.0-offline-routing.md)。
- 保存词句后继续当前对话；模拟练习返回原笔记或任务。结束对话与确认完成分开，适用积分随完成事件原子结算。
- 旧会话原文保留为历史，新练习明确另开；恢复备份不重复发奖。

详细取舍与代价见[实施决策](docs/design/3.0-implementation-decisions.md)。不要为本版配置云服务密钥或创建资源；任何未来启用方案都需要另行设计、授权和验证。不要提交令牌、密钥或真实学习数据。

## 验证

```bash
pnpm verify
pnpm test:e2e
```

使用隔离的测试数据和正确的本地构建，不访问或清空日常浏览器中的学习记录。测试条数和历史 2.x 截图不能替代 3.0 的端到端、隐私、离线和视觉验收；当前证据统一记录在[验证与发布记录](docs/releases/3.0.0-verification.md)，本页不复制会过期的测试总数。

自动化不能代替实体设备：发布前仍需在真实 iPhone Safari/主屏 PWA 与 Android Chrome/已安装 PWA 上复测安全区、动态浏览器工具栏、系统键盘、麦克风权限、录音中断和主屏安装。
